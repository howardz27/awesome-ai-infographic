# Contributing

[中文](#中文)

Open a pull request to add or update a resource. An issue works well for broken links and suggestions that need discussion.

- Pick a resource about generating, editing or evaluating infographics, or building components such as charts and diagrams.
- Link to the canonical repository, skill file, model card, paper, dataset or official product page. Include a demo or paper link if it clarifies what the resource does.
- Add the creation or publication date for each resource link. Label the event and use the precision supported by the source, such as `YYYY-MM-DD` or `YYYY-MM`. Include the GitHub Star count for a repository and refresh the snapshot date when updating all counts.
- Describe the input, output and editing options where relevant. Specify what stays editable, such as source code, native objects, raster layers or a hosted canvas.
- For downloadable weights, name the license shown by the publisher and mention gated access or notable usage restrictions. For projects with public code, check the upstream license before calling them open source.
- Put the entry in the most relevant section, ordered newest first by its first displayed date. Place undated resources last. Update both language editions with the same links and metadata. A contribution in either language is welcome if you need help with translation.
- Check that the link opens and the description matches the primary source. Disclose your relationship to the project if you are affiliated.

Use this format for a list entry.

```markdown
- [Resource name](https://example.com/project) - **Created 2025-05-16 · ★ 120** Generates editable SVG diagrams from a text description.
```

## 中文

添加或更新资源可以提交 Pull Request。失效链接和需要讨论的建议可以通过 Issue 提出。

- 收录与信息图生成、编辑、评估有关的资源，也欢迎能组成信息图的图表与图解项目。
- 链接到官方仓库、技能文件、模型卡、论文、数据集或产品页。若演示或论文能说明能力，可补充链接。
- 为每个资源链接补充创建或发表日期，注明对应事件，并按来源精度填写，例如 `YYYY-MM-DD` 或 `YYYY-MM`。GitHub 仓库请附 Star 数，统一刷新 Star 数时也请更新采集日期。
- 按需说明输入、输出和可编辑范围，例如源码、原生对象、位图图层或在线画布。
- 可下载权重应注明发布方标注的许可，并说明访问门槛或显著的使用限制。将公开代码称为开源前，请核对上游许可证。
- 放入最相关的章节，按第一个标注日期从新到旧排列。未公开日期的条目置于末尾。两个语言版本使用相同的链接和数据。如需翻译协助，先提交任一语言的条目也欢迎。
- 检查链接可访问、描述与一手资料一致。若与推荐项目有关系，请在 PR 中注明。

条目格式如下。

```markdown
- [资源名称](https://example.com/project) - **创建于 2025-05-16 · ★ 120** 根据文字描述生成可编辑的 SVG 图解。
```
